# 阶段6：15秒分镜剧本与对白强化

将阶段5节拍转换为可执行分镜和台词，支持整集与单段返修。

每段先估算对白、动作/反应、停顿和切镜余量，总计不得超过15秒。使用全局唯一ID如 `EP12-T03-S02`；自适应2—6镜；镜头必须承担信息、关系、情绪、动作或反应功能；把说明改为质问、试探、回避、威胁、谈判和反击；区分人物语气；动作遵守接近、接触、受力、移动、释放；段尾状态必须能交给下一段。

每段输出：ID与时间、本段任务、段首状态；逐镜时间/景别/机位/动作/台词/反应/道具；段尾状态、道具、位置、情绪和有效变化；对白/动作/停顿估时；制作难度；阶段7资产包和阶段8执行包。剧情契约过载时退回阶段5。
